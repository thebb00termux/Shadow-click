🔑 Cách lấy API key YouTube (miễn phí)

Key này dùng cho ô Tìm nhạc trên YouTube trong game. Làm một lần, mất khoảng 5 phút. Không cần thẻ thanh toán.

Key là gì? Là một chuỗi bắt đầu bằng AIza dài khoảng 39 ký tự. Google cho mỗi tài khoản 10.000 điểm miễn phí mỗi ngày. Mỗi lần tìm nhạc tốn 100 điểm, tức khoảng 100 lượt tìm mỗi ngày. Nghe nhạc không tốn điểm.

1 Đăng nhập Google Cloud

Mở trang bên dưới và đăng nhập bằng tài khoản Google của bạn.

Mở Google Cloud
Nếu Google báo "Accès à Google Cloud bloqué" hoặc yêu cầu bật xác minh 2 bước (MFA), hãy bấm nút Activer la MFA / Enable MFA, làm theo hướng dẫn (thường nhập số điện thoại và mã SMS), rồi tải lại trang. Có thể mất vài phút.

Nếu có thanh quảng cáo "Commencez l'essai gratuit", bạn cứ bấm Fermer / Close. Bạn không cần dùng bản dùng thử.

2 Chọn hoặc tạo project

Ở thanh trên cùng, bấm tên project hiện tại (hoặc "Select a project"). Chọn một project có sẵn, hoặc bấm New project / Nouveau projet, đặt tên bất kỳ (ví dụ game-nhac) rồi bấm Create / Créer.

3 Bật YouTube Data API v3

Mở trang bên dưới, kiểm tra project ở thanh trên là project vừa chọn, rồi bấm nút xanh Enable / Activer.

Mở trang YouTube Data API v3

Nếu link không mở đúng, vào menu ☰ → APIs & Services → Library, gõ YouTube Data API v3 để tìm.

4 Tạo API key

Mở trang bên dưới, bấm Create credentials / Créer des identifiants rồi chọn API key / Clé API.

Mở trang Credentials

Nếu Google hiện màn hình hỏi bạn muốn truy cập dữ liệu nào:

  • Ở ô Select an API chọn YouTube Data API v3.
  • Chọn Public data / Données publiques (mô tả có ghi sẽ tạo một API key). Đừng chọn User data vì nó tạo OAuth, không phải key.
  • Bấm Next / Suivant, Google sẽ hiện key. Bấm biểu tượng sao chép để lấy key.

5 Hạn chế key (nên làm)

Vì key nằm trong trình duyệt của bạn, hãy khóa nó lại để người khác lấy được cũng không dùng được. Trong danh sách API keys, bấm vào tên key vừa tạo, rồi:

  • Application restrictions (Restrictions relatives aux applications) → chọn Websites / Sites Web → bấm Add / Ajouter → nhập địa chỉ nơi bạn mở game, ví dụ https://ten-ban.github.io/*.
  • API restrictions (Restrictions relatives aux API) → chọn Restrict key / Restreindre la clé → tick YouTube Data API v3.
  • Bấm Save / Enregistrer.
Key sau khi lưu cần vài phút mới có hiệu lực. Nếu bạn mở game trực tiếp từ file trên máy (không qua link web) thì key đã hạn chế theo trang web sẽ bị chặn. Khi đó hãy mở game qua link web.

6 Dán key vào game

Quay lại game, mở thẻ 🎵 Nhạc YouTube, dán key vào ô API key YouTube rồi bấm 💾 Lưu key. Khi thấy dòng ✅ Đã lưu key là xong. Giờ bạn có thể gõ tên bài vào ô Tìm nhạc trên YouTube.

Key chỉ được lưu trên máy của bạn. Bấm 🗑️ Xóa key nếu muốn gỡ.
